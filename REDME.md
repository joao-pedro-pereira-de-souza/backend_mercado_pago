## MERCADO PAGO BACKEND


### Start project


install docker
```
https://docs.docker.com/engine/install/
```

install docker compose
```
https://docs.docker.com/compose/install/
```

Create structure containers docker

```
   docker compose up -d
```

Add seeds database
```
   ./api: npm run seed

```
